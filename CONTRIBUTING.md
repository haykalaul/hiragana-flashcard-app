# Contribution Guidelines for JapCard Mobile App

Thank you for your interest in contributing to JapCard! Contributions from developers, designers, and users help us improve the app continuously.

## How to Contribute

- Fork the repository and create your branch from `main`.
- Make your changes on your branch with clear, descriptive commit messages.
- Ensure code follows the existing style and conventions for consistency.
- Test your changes thoroughly before submitting a pull request.
- Submit a pull request describing your changes and the problem they solve.

## Reporting Issues

- Please use GitHub issues to report bugs or request new features.
- Provide detailed information including steps to reproduce, expected vs actual results, and relevant screenshots or logs.

## Code Style and Practices

- Follow the existing React Native and Streamlit project conventions.
- Keep user experience and accessibility in mind while developing features.
- Write clear, maintainable code with comments and documentation where necessary.

## Communication

- Be respectful and polite in all interactions.
- Discuss larger changes or new features via issues before implementation if possible.
- Ask questions or seek clarifications in the issue or pull request comments.

## License

By contributing to this project, you agree that your contributions will be licensed under the project’s license.
